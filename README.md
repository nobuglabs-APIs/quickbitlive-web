# QuickBit Live Web

Aplicação web do QuickBit Live, construída com React, TypeScript e Vite.

## Desenvolvimento

```bash
npm install
cp .env.example .env
npm run dev
```

Configure `VITE_API_URL` para apontar para a API. Em desenvolvimento, o valor
predefinido é `http://localhost:8000`.

## Verificação

```bash
npm run lint
npm run build
```
